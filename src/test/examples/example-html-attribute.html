Masonry — HTML Data Attribute Example

No JavaScript required — add a data-masonry attribute to your container and Masonry initialises itself automatically when the bundle loads. Options are passed as a JSON string inside the attribute.

Technology
Declarative Setup

Short card — no <script> tag needed. Masonry reads the attribute and initialises itself.

Design
JSON Options

Pass any Masonry option directly in the attribute value as a valid JSON string. Here we set itemSelector, columnWidth, percentPosition, and gutter.

Business
No jQuery Needed

Tiny card — the data attribute path uses plain JavaScript internally.

Tip
CMS-Friendly

Keeping layout options in the markup is handy for CMS-driven pages or templating engines where adding inline scripts is inconvenient or blocked by a CSP policy.

Science
Sizer Element

Even with a data attribute you can reference a CSS selector for columnWidth. This keeps the column width controlled by CSS and makes the layout responsive.

Technology
Responsive Layout

Short card — the column count drops at the same breakpoints as the other examples.

Design
Varying Heights

Cards with different amounts of content pack together tightly — exactly the cascading "stones in a wall" effect Masonry is named after.

Business
Clean Markup

One attribute on the container is all it takes. The items themselves need no special markup beyond the itemSelector class.
