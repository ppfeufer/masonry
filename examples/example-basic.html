Masonry — Basic Example (Vanilla JS)

Initialised with plain JavaScript (new Masonry(element, options)). No jQuery required. The wide card below demonstrates a two-column span.

Technology
Vanilla JS Initialisation

Short card — pass a DOM element or a CSS selector string as the first argument to new Masonry().

Design
Sizer Element

Setting columnWidth to a selector string lets you control the column width entirely in CSS. Resize the window to watch the responsive breakpoints activate.

Business
percentPosition

Tiny card demonstrating the percentPosition: true option.

Science
Wide Card — Two Column Span

This item is twice the width of a normal column. Masonry still packs everything tightly, slotting the wide card into whichever row has the most vertical space available.

Tip
Gutters

Use the gutter option for horizontal spacing between columns. Vertical spacing is set via margin-bottom on each item in CSS.

Technology
No Dependencies

Short card — jQuery is not required for vanilla JS usage.

Design
Horizontal Order

Set horizontalOrder: true to place items in a strict left-to-right order rather than always filling the shortest column.

Business
fitWidth

When fitWidth: true is set the container shrinks to the width of its columns, making it easy to centre the grid with margin: auto.
