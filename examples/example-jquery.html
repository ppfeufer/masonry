Masonry — jQuery Example

Initialised via the jQuery plugin syntax ($('.grid').masonry(options)). The bundle auto-registers $.fn.masonry when jQuery is present — no manual bridging required.

Technology
jQuery Initialisation

Short card — call $('#grid').masonry({…}) inside $(document).ready() and you're done.

Design
Sizer Element

Setting columnWidth to a CSS selector string lets you control column width in CSS rather than hard-coding pixels, keeping the layout fully responsive.

Business
percentPosition

Tiny card — percentPosition: true positions items using percentages instead of pixels.

Tip
Gutters

Use the gutter option to add horizontal spacing between columns. Vertical spacing is controlled via margin-bottom on each item in CSS.

Science
Horizontal Order

Set horizontalOrder: true to place items left-to-right across columns instead of always filling the shortest column first.

Technology
Auto-Bridging

Short card — the bundle detects jQuery at load time and calls jQueryBridget automatically.

Design
fitWidth

When fitWidth: true is set the container shrinks to fit the columns exactly, making it simple to centre the grid with margin: auto.

Advanced option
Business
Dynamic Items

Appending new items at runtime? Call $grid.masonry('appended', $newItems) after adding them to the DOM to re-run the layout.
